# 城堡突袭 · v1.4 dev2（预览版）

**《雨沼边境走廊 · 泥水尽头是学院》**

零依赖、零外部资源的 2.5D 卷轴动作游戏。解压后**双击 `index.html` 即玩**，普通 `<script>` 顺序加载，`file://` 协议下可运行；也可用 `python -m http.server 8000` 等本地服务打开。画面由 WebGL 渲染，配乐与音效由 WebAudio 实时程序化合成，存档走 `localStorage`（键 `castleRaid.save.v1`，<5MB）。

> 本版核心是**第六张、也是目前最大的开放地图【雨沼边境走廊】**（9600px，推荐 Lv.85+），作为下一版本主线区域【魔法大学城】的空间过渡带。游戏内【版本】面板置顶当前预览版公告（新增 / 修复 / 优化 / 变更四类）、下一版计划与完整历史日志；**下一版预告为 v1.4 dev2.1 · 魔法大学城**。

### 野外单位（30 只，数值 ≥ 前图 3 倍）

统一 `BORDER_STAT_MUL = 3.25`，双攻 / 双防 / 生命 / 速度按倍率放大。三类 AI 严格区分：

- **中立**（蓝血条，人不犯我我不犯人）：毒蛙、变色蜥、沼泽鳄、草浮灵；离开仇恨区解除并回满。
- **半中立**（领地巡逻，入侵才仇恨，走远脱战回满）：猪人 ×2（高大胖墩、大砍刀）、匪帮 ×3 + 山匪头子、林间弓手、街头持刀小混子、斧头帮成员、锯齿恶犬、蹦蹦种子。远程单位会主动保持距离射击。
- **敌对 BOSS**：食人魔（暗系、漂浮幽灵形态、法术攻击，暗系技能可致**中毒 / 麻痹**），位于洼地哨塔附近，掉落暗影晶核碎屑 / 暗影晶核（小概率）/ 骨符。

安全区仅存在高属性中立与半中立单位，**无主动敌对怪**；进入时将提示推荐等级 Lv.85+。

## 七、性能预算（N5095 / 核显 / 1K@60FPS）

主画面 1 次 draw call + 高画质 4 个全屏后期 pass；DPR 钳 ≤1，四档画质可切；对象池 + 预分配 TypedArray，逐帧几乎零分配。新地图仍走同一套单 VBO 批次，四区共用一份几何池，不因 9600px 增加 draw call。

实测（真实 Chromium + WebGL 桩，1440×900 高画质）：

| 场景 | 三角形 | draw call |
|---|---:|---:|
| 黄昏城堡 | 1,703 | 5 |
| 狂欢集市 | 5,543 | 5 |
| 星火港 | 6,411 | 5 |
| 魔法丛林 | 7,662 | 5 |
| 蛮荒沼泽 | 12,976 | 6 |
| 雨沼洼地 | 4,208 | 5 |
| 灌木丛林（默认落点） | 5,318 | 5 |
| 农田&破败村落 | 2,960 | 5 |
| 大学城西郊城门 | 2,136~2,439 | 5 |

暂停 / 大地图 / 复活 / 结算 GPU 零提交。⚠️ 沙盒无可用 GPU，**N5095 实机帧率未实测**。进游戏看左下角 HUD 的 `FPS / TRIS / DRAW`，掉帧切「中 / 低 / 省电」。
