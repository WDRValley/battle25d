# 城堡突袭 · 重制版（WebGL 2.5D 卷轴动作游戏）

单页、零依赖、零外部资源的多文件工程。**所有画面由原生 WebGL 绘制，所有声音由 WebAudio 实时合成**，不加载任何图片、音频、模型或第三方库。

---

## 运行

**方式一（最简单）**：双击 `index.html`，用 Chrome / Edge / Firefox 打开即可。脚本使用普通 `<script>` 顺序加载（不是 ES module），因此 `file://` 协议下也能正常工作。

**方式二（推荐，存档最稳）**：在工程目录起一个静态服务器：

```bash
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

> 部分浏览器对 `file://` 页面的 `localStorage` 有限制。程序已做降级处理（存储不可用时游戏照常可玩，只是不保存），若发现设置/背包不持久化，请改用方式二。
> WebAudio 需要一次用户交互才会启动（浏览器自动播放策略），点一下「开始远征」或按任意键即可。

│   │   ├── storage.js         localStorage 封装 + 5MB 预算/裁剪/用量统计

│   │   └── gl.js              WebGL 批渲染器 + FBO 辉光/暗角/调色/色差后期管线
│   ├── game/

│   │   ├── combat.js          普攻/蓄力/技能、伤害结算、敌人 AI、掉落与拾取

**加载顺序**由 `index.html` 末尾的 `<script>` 标签固定：工具 → 配置 → 存储 → 存档 → 音频 → 输入 → 渲染器 → 实体 → 战斗 → 世界 → 画面 → UI → 主循环。各模块挂在全局 `CR` 命名空间下，互不 `import`。

## 操作

| 电脑 | 动作 |
|---|---|
| W / A / S / D | 移动（W/S 同时控制纵深前后） |
| J | 普通攻击 |
| J 长按 ≥0.3s 后松开 | 蓄力攻击（0.3s 一段、约 0.95s 满蓄，伤害与范围大幅提升） |
| K | 跳跃；空中再按一次 = 二段跳 |
| Q / E / R / T | 技能 1 / 2 / 3 / 4 |
| P / Esc | 暂停 / 关闭面板 |
| Tab | 打开面板（角色 / 背包 / 设置 / 操作） |
| 1 / 2 / 3 · 回车 | 菜单选职业 / 开始；结算界面快速重开 |

**改键**：设置 → 键位设置 → 点「修改」→ 按下新键（支持字母、数字 1~4、小键盘、方向键等），Esc 取消。若新键已被别的动作占用，两个动作会自动交换，不会出现抢键。

**手机**：左下虚拟摇杆移动；右下大圆为普攻（长按蓄力），周围四个小圆为技能 1~4，上方为跳跃键。布局参考 MOBA 手游英雄技能键位。触屏键只在对局中出现。

## 已实现功能对照

- **三职业 × 4 技能**：战士（裂地斩/旋风斩/冲锋/战吼）、法师（爆裂火球/冰霜新星/连锁闪电/天陨）、射手（三连箭/箭雨/翻滚齐射/贯穿狙击）。每职业独立 CD 与能量消耗。
- **程序化音频**：`menu / field / battle / boss / victory / defeat` 六套配乐（各自 BPM、调式、和弦、鼓组、音色），按区域自动淡入淡出切换；攻击、暴击、跳跃、二段跳、蓄力充能/释放、火球、冰霜、雷击、爆炸、金币、拾取、升级、号角、受击、护盾等音效全部由振荡器 + 噪声缓冲实时合成。设置面板可分别开关音效/配乐、调节两者音量。
- **画质四档**：高（全后期：亮部提取 → 双向高斯模糊 → 合成，辉光/暗角/色调/色差/颗粒/闪屏）、中（无辉光的合成）、低（直出 + 0.85× 分辨率）、省电（0.7× 分辨率 + 精简场景）。
- **本地存储 5MB 模式**：`castleRaid.save.v3` 保存设置、键位、角色名、等级经验、永久强化、背包、战绩与最近 12 条记录。写入前估算字节数，超过 90% 预算自动裁剪历史与堆叠上限；设置面板实时显示用量。
- **掉落与背包**：金币、6 种材料（铁矿石/魔尘/兽皮/辉晶/古符文/余烬核）、5 种道具（生命药水/能量药剂/锐锋护符/疾风羽/震爆弹）。拾取有磁吸 + 漂字 + 音效，材料可在角色面板消耗做永久强化，道具可在背包点击使用。
- **角色面板**：可编辑角色名、等级经验、7 项属性、5 条强化线、材料收集统计与总战绩。
- **6 类怪物**：中立·草灵（蓝血条，被攻击才反击）、小啰啰（瘦高快速）、步兵（标准）、精英·铁卫（高大重甲 + 远程弹）、小统领（矮胖厚血）、黑石城主（巨型 BOSS，半血召唤援军）。体型由 `w / h / scale / body` 区分高矮胖瘦，并有各自的血条颜色、掉落权重与 AI。
- **画面细节**：斩击弧光、冲击波环、发光体、残影、闪电折线、陨石预警圈、箭雨预警、动态光晕、地面接触阴影 + 日照长投影、斜向体积光、区域氛围微粒、受击闪白/红闪、暴击放大抖动的 WebGL 七段数码伤害漂字、镜头平滑跟随 + 战斗锁定 + 缩放 + 震屏 + 顿挫。
- **区域**：翠风原野（暖阳草原）/ 赤霞隘口（暮色战场）/ 黑石城堡（冷月要塞），天空、山体、地面、色调、环境亮度按位置平滑插值过渡，配乐同步切换，共 8 波 + 最终 BOSS 战。

## 渲染与性能预算

主画面所有几何合并进**一个动态 VBO**，常规情况每帧 **1 次 `drawArrays`**；高画质叠加 4 个全屏后期 pass，合计 5 次 draw call。

| 档位 | draw call | 1K 分辨率 | 实测（1920×1080 仿真） |
|---|---|---|---|
| 高 | 5 | 1920×1080 | ~2200 三角形/帧 |
| 中 | 3 | 1920×1080 | ~2200 三角形/帧 |
| 低 | 1 | 1632×918 | ~2200 三角形/帧 |
| 省电 | 1 | 1344×756 | ~1300 三角形/帧 |

- 无纹理、无后处理贴图、无 shadow map、无深度缓冲；片元着色器仅做一次颜色赋值，遮挡靠按纵深排序的画家算法。
- 固定 1/60s 逻辑步长（单帧最多追 3 步）、对象池 + 预分配 `Float32Array`、圆/环查表，逐帧几乎零分配。
- 批次空间不足时会按图元边界**自动拆成多次 draw call**，不会截断三角形（极端满池压力测试：30 敌 + 420 粒子 + 140 投射物 → 24732 三角形 / 7 次 draw call，顶点数与三角形数严格匹配）。
- 左下角 HUD 实时显示 `FPS / TRIS / DRAW / 分辨率 / 画质档 / 当前配乐`。

> N5095（11 代赛扬、UHD 核显）建议默认「高」，若长时间低于 60FPS 可在设置里切到「中」或「低」。本项目未在 N5095 实机上测过帧率，请以 HUD 读数为准。

## 扩展指引

- **加技能**：在 `js/game/config.js` 的 `CLASSES[i].skills` 增加条目，并在 `js/game/combat.js` 的 `doSkill()` 对应分支实现；技能格、CD、能量、触屏键会自动按数量适配（当前固定 4 个）。
- **加怪物**：在 `config.js` 的 `MOBS` 增加类型并加入 `MOB_ORDER`；`render.js` 的 `drawHumanoid()` 会自动使用其 `w/h/scale/body` 与主色，特殊外形可加分支。
- **加材料/道具**：在 `MATERIALS` / `ITEMS` / `DROP_TABLE` 增加条目，背包与角色面板会自动列出；新道具效果在 `combat.js` 的 `useItem()` 里加分支。
- **加区域/配乐**：在 `ZONES` 增加区域（含天空/山体/地面颜色与 `music` 名），并在 `audio.js` 的 `SCENES` 增加同名编曲配置。
- **改波次**：`WAVES` 数组，`x` 为触发位置，`list` 为敌人类型，`neutral` 为中立怪数量，`boss:true` 标记最终战。

## 已知限制

- 需要支持 WebGL 的浏览器；context 丢失后未做自动恢复（刷新页面即可）。
- `file://` 下 `localStorage` 行为因浏览器而异，已做静默降级。
- 画面主体全部在 WebGL；HUD、面板、菜单等 UI 是 DOM 叠层（不参与场景渲染）。伤害漂字也是 WebGL 绘制的七段数码字形，因此只显示数字与 `+ - ! ★ ◆` 等符号，不显示汉字。
- 键盘固定功能键 P / Esc / Tab / 回车不参与改键，避免与技能键冲突。
