伤害结算与属性口径（完整说明）

分层原则：6 维（物攻 / 法攻 / 物防 / 法防 / 生命 / 速度）是养成本体，写在角色面板；8 维（物攻 / 法攻 / 物防 / 法防 / 命中 / 闪避 / 暴击 / 速度）是战斗时临时等级修正；通用属性是判定率与倍率；种族属性是减伤、特殊与护盾通道。同类百分比加算，不同乘区乘算。

战斗等级乘数M(L)=1+0.1×L，L=clamp(Σ来源等级, −6, +6)；−6 级 = 0.4 倍、0 级 = 1.0、+6 级 = 1.6。多个 buff/debuff 先加总等级再截断，每 10 秒各维向 0 回落 1 级（±6 → 0 需 60 秒）。
8 维战斗值物攻/法攻/物防/法防/速度 = 面板 × M(对应等级)；命中/闪避/暴击 = 基础率 × M(对应等级)。生命不列 8 维，不按 ±10% 修正。
基础判定率命中 95%、闪避 5%、暴击 5%、暴击伤害 150%（clamp 100%~300%）、精准 2%（最高 100%）；全角色基本统一，装备 / 养成提供增量。
种族属性默认每秒回血/回蓝 1；一般抗性 5%（减物法）；真抗 5%（只减固伤）；克制抵抗 2%；微弱抵抗 2%；穿透 2%；穿透抵抗 2%；爆伤抵抗 2%；护盾默认无。

判定顺序（最先到判定完）：① 精准 先 roll，成功则无视免疫 / 闪避 / 无效，直接进伤害计算（不改变伤害数值）；② 命中 = clamp(命中战率 − 闪避战率, 5%, 100%)，未命中本次伤害为 0，固伤默认必中；③ 暴击 = clamp(暴击战率 − 守方暴击抵抗, 0, 100%)，在命中之后；④ 最终爆伤倍率 = clamp(攻方爆伤 − 守方爆伤抵抗, 100%, 300%)，默认 150% − 2% = 148%，暴击乘区 = 倍率/100，非暴击乘 1。

克制原始倍率：微弱 0.5 / 普通 1.0 / 克制 1.5 / 绝克 2.0（水绝克火、木绝克水、火克制冰）。守方修正：R>1 时 R′=max(1, R − 克制抵抗)，R<1 时 R′=min(1, R + 微弱抵抗)，R=1 时不变。例：克制 1.5 → 1.48，微弱 0.5 → 0.52，绝克 2.0 → 1.98。

穿透与抗性：有效穿透 = max(0, 攻方穿透 − 守方穿透抵抗)；有效一般抗性 = max(0, 守方一般抗性 − 有效穿透)；有效真抗同理。一般抗性乘区 = 1 − 有效一般抗性；真抗乘区 = 1 − 有效真抗（抗性上限 90% 待校准）。

伤害十步流程：
① 确定类型：物理（物攻 / 物防 / 一般抗性 / 普通护盾）、法术（法攻 / 法防 / 一般抗性 / 普通与魔法护盾）、固伤（真抗 / 真实护盾）、混合（拆开分别算再合并扣血）。
② 判定：精准 → 命中 → 暴击。
③ 基础伤害 = 攻方战斗值 × 技能威力系数（如 200% = 2.0）。
④ 防御乘区 = K / (防战 + K)，K 按本项目数值体系校准为 180（1.md 示例的 1000 对应千攻量级）；固伤跳过。
⑤ 抗性乘区：物法走一般抗性，固伤走真抗。
⑥ 克制乘区 R′（固伤不吃）。⑦ 暴击乘区（固伤不暴击）。⑧ 其他增伤 / 易伤 / 减伤按乘区连乘。⑨ 随机浮动 ±5%（默认关闭，待校准）。⑩ 护盾最后吸收最终伤害。

最终公式：
物理 = 物攻战 × 威力 × K/(物防战+K) × (1−有效一般抗性) × R′ × 暴击乘区 × 增伤乘区 × 随机
法术 = 法攻战 × 威力 × K/(法防战+K) × (1−有效一般抗性) × R′ × 暴击乘区 × 增伤乘区 × 随机
固伤 = 固伤值 × (1−有效真抗) × 真伤增伤乘区（不吃防御、一般抗性、暴击、克制）
生命伤害 = max(0, 最终伤害 − 对应护盾吸收)。

三类护盾：⛨ 普通护盾（银灰）吸物理 / 法术，不吸固伤；⛨ 法术护盾（蓝）只吸法术；⛨ 真实护盾（橙黄）吸一切含固伤。血条上方按类型分色显示。示例：生命 120、普通护盾 140，受到 100 物理 → 护盾剩 40、生命仍 120；受到 100 固伤 → 普通护盾不吸、生命扣 100。异常状态（中毒 / 烧伤）造成的伤害属于固伤，异常状态系统后续版本开启。

速度与回复：最终速度 = 速度面板 × M(速度等级)；行动条制行动值 = 10000 / 最终速度，越小越先（速度只影响出手顺序 / 频率，不直接乘伤害）；每秒回血 / 回蓝默认 1，每 1 秒独立结算，不受速度影响。

示例：A 物攻面板 1000、物攻 +2 级 → 1200；技能威力 200%；B 物防 500、K=1000；B 一般抗 5%，A 穿透 2%、B 穿透抵抗 2% → 有效穿透 0 → 有效一般抗 5%；克制原始 1.5，B 克制抵抗 2% → 1.48；A 爆伤 150%、B 爆伤抵抗 2% → 148%。非暴击 = 1200×2×1000/(500+1000)×0.95×1.48 ≈ 2249.6；暴击再 ×1.48 ≈ 3329.4。命中 95%−5%=90%，精准 2% 先 roll；若 B 有普通护盾 140，最终伤害先吸 140，剩余扣生命。

待校准参数：K、基础命中/暴击/闪避率、抗性上限、命中下限、随机浮动、多护盾优先级。口径冲突说明：小改第 1 条提到「初始抗性 0」，而 1.md 统一口径给的是 5%；当前按 1.md 实现为 5%，可在 config.js / battlecore.js 把 RACE_DEFAULT.res / trueRes 调为 0 即切换到 0 抗口径。
